상단 또는 아래 시작 버튼으로 2023년 산업연관표 Excel 자료를 불러오세요.
2023 EXTENDED INPUT-OUTPUT TABLE WORKBENCH

브라우저에서 즉시 시뮬레이션합니다

한국은행 2023년 산업연관표(연장표) 4대 분류 체계와 상품분류 계층 데이터를 WebAssembly 기반 Python(NumPy)으로 직접 연산합니다. 별도 서버 없이 모든 행렬 역산과 파급효과 분석이 로컬 브라우저 안에서 투명하게 수행됩니다.

투입계수 A = Z · X̂⁻¹ 레온티에프 역행렬 L = (I - Aᵈ)⁻¹ 생산유발 ΔX = L · ΔY 항등식 검증 vᵀL + 1ᵀAᵐL = 1
대기 중 — 시작 버튼을 누르면 data/ 폴더의 6개 Excel 파일을 자동으로 불러옵니다.
01

4계층 통합 산업분류

대분류(33), 중분류(83), 소분류(165), 기본부문(380) 및 상품분류 계층표를 연동해 거시와 미시를 오가며 분석합니다.

02

전후방 연쇄효과 진단

영향력계수(후방)와 감응도계수(전방)를 4분면 산점도로 시각화해 핵심 기간산업과 최종수요형 산업을 식별합니다.

03

경제파급 시뮬레이터

반도체 수출 증감, 자동차·이차전지 투자 등 최종수요 충격(ΔY)에 따른 생산·부가가치·임금·수입 유발을 산출합니다.

04

수급 항등식 자동 검증

각 분류표의 총산출=총투입 및 총공급=총수요 오차를 자동 검증하고 대분류 하위 드릴다운 비교를 제공합니다.

Workflow
  1. 자료 로딩 — 상단 또는 시작 버튼으로 6개 Excel 파일을 메모리에 로드합니다.
  2. 구조 파악 — 2. 거시·산업 구조에서 총공급·부가가치율·수출입 구조를 확인합니다.
  3. 연관 진단 — 3. 산업연관·전후방에서 특정 산업의 공급망과 유발계수를 조회합니다.
  4. 충격 실험 — 4. 경제파급 시뮬레이션에서 정책·수출 충격(ΔY) 효과를 계산하고 CSV로 저장합니다.
