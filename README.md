# 2023년 한국 산업연관표 분석 웹앱 (Input-Output Analysis Simulator)

한국은행 **2023년 산업연관표(연장표, 생산자가격)**를 기반으로 대분류(33부문)·중분류(83부문)·소분류(165부문)·기본부문(380부문) 및 상품분류 체계를 통합 분석할 수 있는 웹 애플리케이션입니다.  
별도의 서버 설치 없이 브라우저 내부의 **Pyodide(WebAssembly Python + NumPy + OpenPyXL)** 환경에서 행렬 연산과 경제파급 시뮬레이션을 실시간으로 수행합니다.

- **웹앱 접속 주소**: https://kcw01820.github.io/io-analysis/

---

### 포함 데이터 (`data/` 폴더)
- `(표)(2023연장)투입산출표_생산자가격_통합대분류.xlsx` (33부문)
- `(표)(2023연장)투입산출표_생산자가격_통합중분류.xlsx` (83부문)
- `(표)(2023연장)투입산출표_생산자가격_통합소분류.xlsx` (165부문)
- `(표)(2023연장)투입산출표_생산자가격_기본부문.xlsx` (380부문)
- `(표)상품분류.xlsx` (대 → 중 → 소 → 기본부문 계층 매핑)
- `2023년 산업연관표(연장표).xlsx`

### 단위 기준
- **금액**: `백만원` (요약 카드와 표 내부에는 가독성을 위해 `조원` / `억원` 환산치를 병기)
- **비중 및 비율**: `%` (부가가치율, 중간투입률, 수출률, 수입의존도 등)
- **유발계수**: 무차원 배수 (최종수요 1단위(1원) 증가 시 유발되는 생산·부가가치·수입 단위)
- **영향력계수 / 감응도계수**: 전체 산업 평균을 `1.000`으로 정규화한 지수

## 2. 웹앱 사용법

1. **자료 불러오기**
   - 첫 화면에서 **`[분석 시작하기]`** 버튼을 누르면 저장소 `data/` 폴더의 6개 Excel 파일을 자동으로 불러옵니다.
   - 필요 시 **`[내 PC Excel 열기]`** 또는 상단 **`[파일 선택]`**을 통해 로컬 `.xlsx` 파일을 직접 업로드할 수 있습니다.
2. **분석 분류 및 파급모형 선택**
   - 상단 우측 드롭다운에서 **`대분류(33) / 중분류(83) / 소분류(165) / 기본부문(380)`** 중 분석할 분류 수준을 선택합니다.
   - 파급모형은 **`국산거래표 추정(수입누출 반영)`**과 **`총거래표 기준(수입포함)`** 중 선택할 수 있습니다.
3. **탭별 주요 기능**
   - **거시 · 산업 구조**: 총공급·총산출·부가가치·수출입 KPI, 상위 10개 산업 막대그래프, 최종수요·부가가치 항목별 구성, 전체 산업 구조표 조회 및 CSV 저장
   - **산업연관 · 전후방**: 선택한 산업의 생산·부가가치·수입유발계수, 후방 투입구조 Top 10, 전방 배분구조 Top 10, 생산유발 파급 Top 10, 전후방 연쇄효과 4분면 산점도(마우스 오버 시 산업 정보 표시, 클릭 시 해당 산업으로 이동)
   - **시뮬레이션**: 빠른 프리셋(반도체 수출 ±10조원, 자동차·이차전지 +5조원, 건설·SOC +3조원, 음식숙박·운송 +2조원) 또는 사용자 직접 입력으로 최종수요 충격($\Delta Y$) 설정 후 파급효과 계산 및 CSV 저장
   - **정합성 · 드릴다운**: 4개 분류별 총산출=총투입 및 총공급=총수요 항등식 오차 자동 검증, 대분류 내 중/소/기본부문 하위 분해 비교
   - **원자료 · 상품분류**: Excel 파일별 시트 검색·미리보기 및 상품분류 계층 검색 후 연관분석 탭 바로가기

## 3. 분석 방법론 및 수식

### 1) 투입계수 및 수입조정 모형
- **기술투입계수 행렬**: $A_{ij} = \frac{Z_{ij}}{X_j}$ (국내 총산출 $X_j = 0$인 부문은 열 전체를 $0$으로 처리)
- **국산거래표 추정(경쟁수입 조정)**: 2023년 연장표는 국산·수입이 합산된 총거래표이므로, 부문별 국내수요 대비 수입비율 $m_i$를 이용해 국산투입계수($A^d$)와 수입투입계수($A^m$)를 추정합니다.
  $$m_i = \frac{M_i}{\text{총수요}_i - \text{수출}_i}, \quad A^d = (I - \hat{m})A, \quad A^m = \hat{m}A$$
- **총거래표 기준**: 수입 누출 없이 $A^d = A, \; A^m = 0$ 으로 계산합니다.

### 2) 레온티에프 역행렬 및 유발계수
- **생산유발계수 행렬**: $L = (I - A^d)^{-1}$ (특정 산업 $j$의 생산유발계수는 $j$열 합 $\sum_i L_{ij}$)
- **부가가치유발계수**: $v^T L$ ($v_i = \text{부가가치}_i / X_i$)
- **간접 수입유발계수**: $\mathbf{1}^T A^m L$
- **항등식 검산**: 모든 정상 부문($X_j > 0$)에 대해 국산거래표 추정 모형에서는 **부가가치유발계수 + 간접 수입유발계수 = 1.000**이 성립하며, 총거래표 모형에서는 **부가가치유발계수 = 1.000**이 성립합니다.

### 3) 전·후방 연쇄효과 (4분면 포지셔닝)
- **영향력계수 (후방연쇄)**: $BL_j = \frac{\sum_i L_{ij}}{\frac{1}{n}\sum_i \sum_k L_{ik}}$
- **감응도계수 (전방연쇄)**: $FL_i = \frac{\sum_j L_{ij}}{\frac{1}{n}\sum_k \sum_j L_{kj}}$
- 두 계수의 `1.0` 기준선을 중심으로 산업을 **핵심기간산업형($FL \ge 1, BL \ge 1$)**, **최종수요제조형($FL < 1, BL \ge 1$)**, **중간재기초형($FL \ge 1, BL < 1$)**, **독립산업형($FL < 1, BL < 1$)**으로 구분합니다.

### 4) 경제파급 시뮬레이션
최종수요 충격 벡터 $\Delta Y$가 주어질 때 다음 지표를 산출합니다.
- **생산유발액**: $\Delta X = L \Delta Y$ (간접유발액 $= \Delta X - \Delta Y$)
- **부가가치유발액**: $\Delta V = \hat{v} \Delta X$
- **피용자보수(임금) 유발액**: $\Delta W = \hat{w} \Delta X$
- **중간재 수입유발액**: $\Delta M = A^m \Delta X$ (항등식: $\sum \Delta V + \sum \Delta M = \sum \Delta Y$)
