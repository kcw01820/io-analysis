# 산업연관표 분석실

산업연관표 Excel 파일을 브라우저에서 불러와 시트와 산업 항목을 탐색하고, 투입계수행렬 A로부터 레온티에프 역행렬 `(I-A)^-1` 및 생산유발계수 합계를 계산하는 정적 웹앱입니다.

## 실행 및 배포

1. 저장소 최상위(root)에 `index.html`, `style.css`, `app.js`를 둡니다.
2. 산업연관표 Excel 파일을 `data/io-2023.xlsx`라는 이름으로 `data` 폴더 안에 넣습니다.
3. GitHub 저장소의 **Settings → Pages → Deploy from a branch → main → /(root) → Save**를 선택합니다.
4. 배포가 끝나면 `https://사용자이름.github.io/저장소이름/`으로 접속합니다.
5. **기본 자료 불러오기**를 누르면 `data/io-2023.xlsx`를 읽습니다. 또는 **엑셀 파일 선택**으로 다른 파일을 직접 선택할 수 있습니다.

## 분석 기능과 주의사항

- 엑셀 파일의 시트 목록을 자동으로 읽습니다.
- 선택한 시트의 표를 미리 보고, 셀 내용으로 검색할 수 있습니다.
- 생산유발효과 분석은 사용자가 지정한 정방행렬 범위를 투입계수행렬 A로 간주해 `(I-A)^-1`을 계산합니다.
- 행 시작/열 시작은 1부터 세며, 산업 개수만큼 정방행렬 범위를 읽습니다.
- **중요:** 거래표(금액 행렬) 자체를 A로 넣으면 안 됩니다. 분석 전에 거래표를 총산출액으로 나누어 투입계수행렬로 변환한 자료를 사용해야 합니다. 산업연관표의 행·열 배치와 산업분류에 따라 실제 데이터의 시작 위치를 확인해야 합니다.
- 열합계는 해당 열 산업의 최종수요가 1단위 증가할 때 유발되는 전체 산업 생산의 합계로 해석합니다. 결과의 산업 순서는 원본 행렬의 순서와 같습니다.
- Excel 처리는 SheetJS 라이브러리를 CDN으로 불러옵니다. 따라서 첫 실행 시 인터넷 연결이 필요합니다.
- 파일은 브라우저 안에서 처리되며 웹앱 서버로 전송하지 않습니다.

## 파일 구성

- `index.html`: 화면 구성
- `style.css`: 디자인
- `app.js`: Excel 불러오기, 시트 탐색, 행렬 계산
- `data/`: 기본 Excel 자료를 넣는 폴더
- `.nojekyll`: GitHub Pages 정적 파일 게시 설정
