# 2023년 산업연관표(연장표) 분석 웹앱

한국은행이 공표한 **2023년 산업연관표(연장표, 생산자가격 총거래표)**와 **상품분류표**를 활용하여, 브라우저 내에서 Python(Pyodide + NumPy + OpenPyXL)으로 산업구조 분석, 전·후방 연쇄효과 계측, 최종수요 충격 시뮬레이션을 수행하는 정적 웹 애플리케이션입니다.

## 1. 파일 구조

```text
├── index.html          # 대시보드 화면 및 입력/결과 UI
├── style.css           # 레이아웃 및 반응형 스타일
├── app.js              # Excel 로딩(fetch/upload), 상태 관리, 테이블·SVG 시각화, CSV 내보내기
├── worker.js           # Web Worker 내 Pyodide(numpy, openpyxl) 로드 및 Python 호출
├── model.py            # Excel 파싱, 상품분류 계층 매핑, 레온티에프 역행렬 및 시뮬레이션
├── .nojekyll           # GitHub Pages 정적 파일 그대로 게시
├── README.md           # 사용법 및 분석 방법론 설명
└── data/
    ├── (표)(2023연장)투입산출표_생산자가격_통합대분류.xlsx
    ├── (표)(2023연장)투입산출표_생산자가격_통합중분류.xlsx
    ├── (표)(2023연장)투입산출표_생산자가격_통합소분류.xlsx
    ├── (표)(2023연장)투입산출표_생산자가격_기본부문.xlsx
    ├── (표)상품분류.xlsx
    └── 2023년 산업연관표(연장표).xlsx
